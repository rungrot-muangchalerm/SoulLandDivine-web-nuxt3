# คู่มือความสามารถระบบจัดการ GM

เอกสารนี้สรุปความสามารถของหน้าเว็บ Nuxt/Nitro ที่ root ของโปรเจ็กต์ โดยอิงจากเมนูและ API ที่มีอยู่ในโค้ดปัจจุบัน การทำรายการกับข้อมูลเกมจะสำเร็จได้เมื่อเชื่อมต่อฐานข้อมูลและ Game Server ที่เกี่ยวข้องแล้ว

## ภาพรวม

ระบบนี้ใช้จัดการข้อมูลผู้เล่นและงานดูแลเกมจากหน้าเว็บเดียว ได้แก่ ดูรายชื่อผู้เล่นในเซิร์ฟเวอร์ จัดการสิทธิ์และช่องทาง ส่งประกาศ/อีเมล จัดการเซิร์ฟเวอร์ ตลอดจนค้นหาบันทึกการเล่นและการเงิน เมนูที่เห็นจะขึ้นอยู่กับสิทธิ์ของบัญชี

## ความสามารถตามเมนู

### ข้อมูลผู้เล่น

- เลือกเซิร์ฟเวอร์เพื่อดูบัญชีผู้เล่นที่มีตัวละครอยู่ในเซิร์ฟเวอร์นั้น แบ่งหน้า หน้าละ 50 บัญชี
- ดู UID และบัญชีผู้เล่น ช่องทาง วันที่สมัคร เวลาเข้าเกมล่าสุด จำนวนตัวละคร และยอดเติมสะสมรวมของตัวละครในเซิร์ฟเวอร์นั้น
- ขยายแถวผู้เล่นเพื่อดูตัวละคร ทรัพยากร และยอดเติมรายตัวละคร
- สั่งระงับ/ยกเลิกการระงับแชตหรือบัญชีเป็นรายตัวละคร โดยระบุระยะเวลาและเหตุผลเมื่อเกี่ยวข้อง
- สถานะออนไลน์แสดงว่าไม่ทราบ เนื่องจากฐานข้อมูลที่เชื่อมต่อไม่มีสถานะออนไลน์แบบเรียลไทม์

### หักทรัพยากร

- เลือกเซิร์ฟเวอร์เพื่อดูรายการไอเทมและทรัพยากรทั้งหมด แบ่งหน้า หน้าละ 50 รายการ
- เลือกรายการที่รองรับเพื่อหักจากตัวละครเจ้าของได้
- ยอดสกุลเงินและประเภทไอเทมที่ยังไม่มีชนิดคำสั่งหักตรงกันจะแสดงอย่างเดียว
- หักความคืบหน้าการเติมเงินสะสม
- หักความคืบหน้าการเติมเงินกิจกรรม

### ประกาศข้อความ

- สร้าง ค้นหา แก้ไข และลบประกาศ
- กำหนดเซิร์ฟเวอร์หรือทุกเซิร์ฟเวอร์ ผู้ส่ง หัวข้อ เนื้อหา และประเภทประกาศ
- ตั้งเวลาเริ่ม/สิ้นสุดและช่วงเวลาสำหรับประกาศแบบวนซ้ำ หรือกำหนดให้ส่งครั้งเดียว

### ประกาศไฟล์

- อัปโหลดและดาวน์โหลดไฟล์ประกาศด้วยชื่อไฟล์
- ต้องตั้งค่า Announcement Service ก่อนใช้งาน

### อีเมล

- ส่งอีเมลถึงผู้เล่นหรือทุกเซิร์ฟเวอร์
- ระบุเทมเพลตและรางวัลที่แนบได้สูงสุดสามรายการ

### เติมเงินย้อนหลัง

- ส่งคำสั่งเติมรายการสั่งซื้อให้ UID บนเซิร์ฟเวอร์ที่เลือก โดยกรอกหมายเลขคำสั่งซื้อ ข้อมูลคำสั่งซื้อ และจำนวนเงิน

### คำต้องห้าม

- เพิ่มคำลงในรายการคำต้องห้ามของเกม

### เปิดเซิร์ฟเวอร์ด่วน

- ค้นหาเซิร์ฟเวอร์ตามช่องทางและช่วงรหัสเซิร์ฟเวอร์
- ดูจำนวนผู้ลงทะเบียนและสถานะเซิร์ฟเวอร์
- เปิด/ปิดเซิร์ฟเวอร์ เปิด/ปิดปรับปรุงรายเซิร์ฟเวอร์หรือทุกเซิร์ฟเวอร์
- เปิดสถานะแนะนำเซิร์ฟเวอร์ (เมื่อเปิดแล้วหน้าเว็บไม่ให้ปิดด้วยสวิตช์)

### รายงาน

- ค้นหารายงานตามประเภทและช่วงเซิร์ฟเวอร์
- ระงับการแชต ระงับบัญชี หรือละเว้นรายงาน

### จัดการของรางวัล

- จัดการระดับของรางวัล: ค้นหา เพิ่ม แก้ไข และลบ
- ตั้งชื่อ เนื้อหาของรางวัลครั้งแรก/ประจำ ประเภทรอบ รอบเวลา และเวลามอบรางวัล
- ค้นหา เพิ่ม หรือลบรายการมอบของรางวัลให้ผู้เล่นตามเซิร์ฟเวอร์และ UID

### ค้นหาบันทึก

- ค้นหาประวัติการใช้และได้รับไอเทม
- ค้นหาประวัติการใช้และได้รับสกุลเงิน
- ค้นหาประวัติเข้า/ออกจากเกม
- ค้นหาประวัติการเติมเงิน
- ใช้ตัวกรองตามเซิร์ฟเวอร์ ผู้เล่น ไอเทม/ประเภท และช่วงเวลา ตามหน้าที่เลือก

### จัดการการตั้งค่า

- ดู เพิ่ม แก้ไข และลบข้อมูลช่องทาง เช่น ชื่อ รหัสช่องทาง IP และ URL

### จัดการสิทธิ์

- ดู เพิ่ม แก้ไข และลบบัญชีผู้ใช้
- กำหนดระดับสิทธิ์และช่องทางที่บัญชีเข้าถึงได้
- รีเซ็ตรหัสผ่านผู้ใช้
- ค้นหาประวัติการดำเนินการและจำนวนรายการตามผู้ใช้ ประเภท และช่วงเวลา

### บัญชีผู้ใช้

- เปลี่ยนรหัสผ่านของบัญชีตนเอง
- ออกจากระบบ

## ระดับสิทธิ์

| สิทธิ์ | ขอบเขตเมนู |
|---|---|
| `admin` | ใช้งานทุกเมนู รวมถึงประกาศไฟล์ จัดการช่องทาง และจัดการบัญชี/ประวัติการดำเนินการ |
| `server` | เมนูเปิดเซิร์ฟเวอร์ด่วนและจัดการช่องทาง |
| `0` | ข้อมูลตัวละครและค้นหาบันทึก |
| `1` | เมนูระดับ 0 และเมนูจัดการคำต้องห้าม/รายงาน |
| `2` | เมนูระดับ 0–1 และประกาศข้อความ |
| `3` | เมนูระดับ 0–2 รวมถึงอีเมล เติมเงินย้อนหลัง และจัดการของรางวัล |
| `4` | เมนูระดับ 0–3 และหักทรัพยากร |

บัญชีเดิมที่เก็บสิทธิ์เป็น `senior` จะถูกตีความเป็น `admin` เมื่อเข้าสู่ระบบ เพื่อรองรับบัญชีผู้ดูแลที่สร้างจากระบบเดิม

## สิ่งที่ต้องพร้อมก่อนใช้งาน

- ฐานข้อมูล MySQL/MariaDB ต้องตั้งค่าตาม `.env` และมี schema ที่จำเป็น
- บัญชีผู้ใช้ต้องมีสิทธิ์ในช่องทางที่เลือกขณะเข้าสู่ระบบ
- รายการเซิร์ฟเวอร์อ่านจากไฟล์ XML ใน `data/server_list/`
- งานที่เปลี่ยนข้อมูลในเกม เช่น ค้นหาตัวละคร ส่งอีเมล หรือเปิด/ปิดเซิร์ฟเวอร์ ต้องตั้งค่า `GAMESERVER_HOST` และ `GAMESERVER_PORT` ให้เข้าถึง Game Server ได้
- การอัปโหลดประกาศต้องตั้ง `ANNOUNCEMENT_SERVICE_URL` และ `ANNOUNCEMENT_SERVICE_TOKEN`; การดาวน์โหลดต้องเข้าถึง Announcement Service ได้
- ประกาศข้อความและประวัติการดำเนินการอาศัยตารางในฐานข้อมูล

## ขอบเขตที่ไม่ได้อยู่ในเมนูปัจจุบัน

หน้าจัดการเส้นทางการใช้/ได้รับทรัพยากรและหน้าจัดการประเภทการหักทรัพยากรเดิมยังไม่เปิดในเมนูใช้งานหลัก แม้จะยังมีหน้าอ้างอิงอยู่ในโปรเจ็กต์ก็ตาม
